# Участие в разработке

Перед изменениями прочитайте README, создайте отдельную ветку и запустите тесты. Для ошибки приложите шаги воспроизведения и версию ОС. Изменения должны сохранять пользовательские данные и не отправлять их в сеть без явного действия пользователя. Не добавляйте личные профили, токены, .env и сборки в Git.

В Pull Request кратко укажите проблему, поведение после изменения и выполненные проверки. При существенной помощи ИИ опишите её.
