# Собственная синхронизация Learning OS

Публичные сборки по умолчанию работают локально. Данные автора и его Supabase-проект в них не используются. Для собственного облака:

1. Создайте новый проект Supabase под своим аккаунтом. Параметры тарифа и ограничения проверяйте у Supabase; бесплатная работа без ограничений не обещается.
2. В SQL Editor нового проекта выполните `supabase/setup-sync.sql` из этого репозитория. Он создаёт таблицу, ограничения, RLS-политики и функцию сохранения с проверкой версии. Скрипт предназначен для нового проекта; не применяйте его к чужой рабочей базе без отдельной проверки.
3. В Auth включите вход по email/password. Настройте подтверждение email и доставку писем.
4. Для веб-версии настройте Site URL и разрешённые Redirect URLs своего сайта, включая путь /sync/. Используйте реальные адреса собственной сборки.
5. Скопируйте `.env.example` в `.env.local`. Впишите свой Project URL и **publishable key**. Service-role и secret key в приложении и NEXT_PUBLIC-переменных использовать нельзя.
6. Выполните `npm run build`. Для Windows затем `npm run desktop:build`; для Android — `npm run android:sync` и Gradle assembleDebug. Одни и те же URL и publishable key должны быть встроены в обе платформы.
7. На исходном устройстве войдите и выберите «Использовать данные этого устройства». На втором войдите в тот же аккаунт и выберите «Получить данные из облака». Перед первой синхронизацией сохраните JSON.

Секретный серверный ключ не нужен. Publishable key рассчитан на клиентский код, а изоляцию данных обеспечивает RLS. В каждой строке проверяется auth.uid() = user_id; RPC работает с правами вызывающего пользователя (security invoker). Изменение одной и той же записи на двух устройствах требует разрешения конфликта.

Локальная проверка схемы: `npm run test:database` — используется отдельный PostgreSQL WASM без подключения к сети и реальному Supabase. Этот тест не проверяет доставку писем и настройки вашего облака.

Документация: [API keys](https://supabase.com/docs/guides/getting-started/api-keys), [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), [Redirect URLs](https://supabase.com/docs/guides/auth/redirect-urls).
