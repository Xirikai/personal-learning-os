# Сообщения о проблемах безопасности

Проект экспериментальный, гарантированного срока исправлений нет. Перед публикацией отчёта удалите личные данные. Ключи, пароли и содержимое резервных копий не размещайте в Issues. Если доступно, используйте приватное сообщение о проблеме через вкладку Security репозитория; иначе сначала откройте Issue без чувствительных деталей.

Выполняйте работу с важными файлами после создания резервной копии. Автоматическая загрузка новых версий приложений не включена.
