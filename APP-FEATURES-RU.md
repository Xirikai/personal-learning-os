# Personal Learning OS 0.2 — функции и идеи

Этот файл фиксирует состав расширенной версии приложения. Искусственный интеллект отложен по вашему последнему решению. Все расчёты выполняются локальными алгоритмами.

## Как пользоваться

### Календарь

Откройте Planner и выберите «Неделя», «День», «Список» или «Месяц». Нажмите «Событие» либо нужный час. Выберите категорию и повторение. События резервируют время при расчёте учебного плана.

Перетаскивание предлагает новое время. Оно вступает в силу после сохранения формы. Перенос повторяющегося события меняет только выбранное повторение. Обычное редактирование через нажатие на событие относится ко всей серии.

### Недельный план

Нажмите «Распланировать неделю», выберите первую дату, учебные дни, время, усталость и дневной лимит. Приложение распределит длительности незавершённых задач без повторного учёта уже распределённых минут. Сначала показывается результат; кнопка «Применить неделю» заменяет планы только показанных учебных дней. Более ранние блоки текущего дня сохраняются. Дедлайны задач не меняются.

Если задача выполнена частично, перед расчётом уточните её оставшуюся длительность. Фактическое выполнение не определяется по факту наличия блока в календаре.

### Повторение материала

Откройте заметку и нажмите «Сделать карточку повторения» либо создайте карточку в разделе «Повторение». Посмотрите ответ и выберите «Помню» или «Повторить завтра». Успешные повторения увеличивают интервал. Приложение не генерирует ответы самостоятельно.

### Поиск и фокус

Ctrl+K открывает поиск задач, заметок, событий, привычек и карточек. Ссылка «Фокус» у задачи выбирает её в таймере; отсчёт запускается кнопкой «Старт». «Режим фокуса» скрывает остальную навигацию.

## Ограничения текущей версии

- Подключение Google-аккаунта и двусторонняя онлайн-синхронизация Google Calendar не добавлены. Обмен идёт через файл .ics.
- Импорт .ics поддерживает отдельные события, простые ежедневные/еженедельные серии и исключённые даты. Сложные RRULE, COUNT/BYDAY и серии в другой временной зоне пропускаются с объяснением. Отдельные события с UTC/TZID преобразуются во время устройства.
- Напоминание отображается внутри открытого приложения. Фоновые push-уведомления после закрытия не добавлены.
- Умный план — воспроизводимая эвристика. Он не заявлен как математически оптимальный.
- Полная локализация всего старого приложения не выполнялась. Smart Planner и основной календарь поддерживают RU/EN; новые дополнительные разделы прежде всего на русском.
- Markdown поддерживается в ограниченном текстовом варианте: заголовки, жирный текст, строки кода, списки и цитаты. HTML не исполняется.
- Файл Windows предназначен для 64-разрядной Windows. Сборка не подписана коммерческим сертификатом.
- Данные браузерного сайта и отдельного Windows-приложения хранятся раздельно. Для переноса используйте JSON-экспорт/импорт.
